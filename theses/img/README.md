# Thesis cover images

Cover thumbnails for the archive, one per entry in `_data/geotheses.yml`.
They are generated by `scripts/thesis_covers.py` (page 1 of the thesis
PDF, rendered as JPEG) and follow one canonical scheme:

    <year>_<Surname>.jpg

ASCII-folded (Köbben -> Kobben) and hyphenated (van der Ham ->
van-der-Ham); when that name is taken the given name is appended
(`2015_Wu_Haoxiang.jpg`). Everything is JPEG regardless of what older
hand-saved files looked like — please keep it that way.

The archive page picks the images up at the next build: it checks
`site.static_files`, so entries whose file is absent show a placeholder
instead of a broken image. Keep the filenames exactly as in the YAML.
